Read-only access to room master-data. Retrieve information about rooms and locations for timetable displays, room booking systems, and facility management integrations.

v1  Read-only   **Endpoints:** 2

---

## Use cases

Timetable display

Show room assignments alongside timetable data.

Facility management

Integrate room information into campus maps and navigation tools.

---

## Endpoints

| Method | Operation ID | Description |
| --- | --- | --- |
| `GET` | `getRoomById` | Get a single room by ID |
| `GET` | `getRooms` | List all rooms |
